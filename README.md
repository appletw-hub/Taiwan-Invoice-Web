# 台灣發票 PDF 智慧解析與核對系統 (Taiwan Invoice Web)

> 一款專為台灣會計、出納、報稅及行政人員打造的智慧發票辨識與核對工具。支援將多頁掃描檔、拍照圖片與電子發票彙整之 PDF 自動提取為結構化明細，提供 5% 營業稅即時推算連動，並可自選欄位匯出 Excel。

---

## 🌟 核心特色

- **多模態 AI 智慧辨識**：支援多頁 PDF，一次解析多張發票。無論是手機拍照、紙本掃描、收銀機二/三聯式或電子發票證明聯皆可精確提取。
- **稅額即時雙向連動**：切換稅別（應稅 5%、零稅率 0%、免稅），系統自動計算銷售額（未稅）、營業稅與總金額（含稅），修改任一數值即時自動重新推算。
- **國稅局扣抵憑證格式自動判別**：
  - `21`：三聯式、電子計算機統一發票
  - `22`：二聯式收銀機統一發票、載有稅額憑證
  - `25`：三聯式收銀機統一發票及電子發票證明聯
  - `28`：海關代徵營業稅繳納證扣抵聯
  - `99`：其他收據與憑證
- **彈性匯出 Excel 報表**：提供 12 個標準欄位自選勾選匯出（`.xlsx`），格式精準符合財務核銷流程。
- **純前端零伺服器・資料高隱私**：所有發票資料與 Gemini API Key 均保存在使用者本機瀏覽器 LocalStorage，辨識請求直接與 Google 官方 API 通訊，伺服器不保存任何隱私或營業資料。
- **日系戶外工裝大地質感風格**：採用 PANTONE 戶外色系（漂白砂色、橡皮色、仙人掌綠、知更鳥灰藍、翠藍眼蛺蝶），呈現沉穩溫潤的視覺體驗。

## 🚀 快速開始

本系統設計為**開箱即用**，無須複雜的後端環境建置：

### 方法一：雙擊捷徑啟動（推薦 Windows 使用者）
在專案目錄下直接雙擊 **`啟動發票系統.bat`**，系統會自動在預設瀏覽器中開啟本系統。

### 方法二：透過 Node.js 本地伺服器
```bash
node server.js
```
開啟瀏覽器前往：`http://localhost:5173`

### 方法三：直接開啟
直接用任一現代瀏覽器（Chrome, Edge, Safari）開啟專案根目錄下的 **`index.html`** 即可。

## 🔑 Gemini API Key 設定

本系統使用 Google Gemini 多模態模型進行精準發票 OCR 辨識：

1. 前往 [Google AI Studio](https://aistudio.google.com/app/apikey) 免費申請個人專屬 API Key。
2. 啟動系統後，點擊右上角「**鍵入 API Key**」。
3. 貼上您的金鑰並選擇辨識模型（預設推薦極速的 `gemini-3.1-flash-lite` 或最新款 `gemini-3.6-flash`），點擊儲存即可開始解析發票。

## 📋 支援核對欄位 (12 大項目)

1. **廠商名稱** (賣方名稱)
2. **統一編號** (8 碼統編)
3. **貨款月份** (YYYY-MM，支援整批快速批次套用)
4. **憑證格式** (21 / 22 / 25 / 28 / 99)
5. **發票日期** (西元 YYYY-MM-DD)
6. **發票號碼** (兩碼英文字軌 + 8 碼數字)
7. **稅別標籤** (應稅 / 零稅率 / 免稅)
8. **銷售額** (未稅金額)
9. **稅額** (營業稅 5%)
10. **發票金額** (含稅總額)
11. **品項內容** (明細品名與規格)
12. **收付款日** (支援整批快速批次套用)
13. **備註**

## 🛠️ 技術棧

- **核心架構**：React 18 + Babel Standalone
- **樣式設計**：Tailwind CSS (自訂 PANTONE Earth-Tone 色盤)
- **報表匯出**：SheetJS (xlsx)
- **多模態解析**：Google Gemini API (Generative Language API)
- **本機伺服器**：Node.js 原生 HTTP 伺服器
